# Малярка43

Сайт кузовной мастерской «Малярка43» в Кирове.

Текущая версия: https://malyarka43.closedlaugh2.chatgpt.site

## Возможности

- Адаптивный интерфейс в фирменной чёрно-бело-красной палитре.
- Услуги, контакты, интерактивная карта, Telegram и ВКонтакте.
- Вращаемый Mercedes-Benz S65 W222 с выбором 18 участков для заявки.
- Реальные фотографии до и после ремонта с перетаскиваемым разделителем.
- Отзывы из 2ГИС: выбранные фрагменты с авторами, датами и ссылками; снимок данных на 23.11.2026.
- Форма записи с фотографиями; хранение заявок в Cloudflare D1 и файлов в R2.
- Защищённый раздел владельца `/manage`.

## Запуск

Нужен Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

Локальный адрес: http://127.0.0.1:5173. Инструкции для базы, локальной авторизации и сборки: [README.technical.md](README.technical.md).

```sh
npm run build
node node_modules/typescript/bin/tsc --noEmit
node scripts/check-leads.mjs
node scripts/check-car-model.mjs
```

## Сервер и уведомления

Проект использует React, TypeScript, Vinext, Three.js и Cloudflare Workers. Для полной работы формы нужны D1 и R2; обычный статический GitHub Pages не выполняет серверные обработчики.

В [`.env.example`](.env.example) перечислены настройки владельца и уведомлений. Значения задаются в окружении хостинга. Доставка в Telegram и по почте требует настройки Telegram-бота и Resend; эти сервисы пока не подключены.

Репозиторий содержит исходники и используемые медиа. Заявки клиентов, локальная база, загруженные клиентами файлы, зависимости и секреты в него не входят. Текущий сайт продолжает работать на Sites; этот репозиторий сам по себе не меняет хостинг и не настраивает автоматическую публикацию.

## Структура

- `app/` — страницы, блоки интерфейса и API заявок.
- `public/` — логотип, изображения и 3D-модель.
- `db/`, `drizzle/` — схема базы и миграции.
- `worker/`, `scripts/` — сервер и инструменты сборки.
- [PROJECT.md](PROJECT.md) — состав сайта и оставшиеся настройки.
- [ASSETS.md](ASSETS.md) — происхождение фотографий, иллюстраций и модели.
