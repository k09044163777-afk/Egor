# Малярка43

Сайт кузовной мастерской «Малярка43» в Кирове.

Рабочий адрес: https://malyarka43.danil43.workers.dev

## Возможности

- Адаптивный интерфейс в фирменной чёрно-бело-красной палитре.
- Услуги, контакты, интерактивная карта, Telegram и ВКонтакте.
- Вращаемый Mercedes-Benz S65 W222 с выбором 18 участков для заявки.
- Фотографии до и после ремонта с перетаскиваемым разделителем.
- Отзывы из 2ГИС с авторами, датами и ссылками на источник.
- Форма записи с фотографиями, хранение заявок в D1 и файлов в Workers KV.
- Защищённый раздел владельца /manage.
- Telegram-бот с услугами, контактами, записью и уведомлениями о заявках.

## Запуск

Нужен Node.js 22.13 или новее.

~~~sh
npm ci
npm run dev
~~~

Локальный адрес: http://127.0.0.1:5173.

~~~sh
npm run build
node node_modules/typescript/bin/tsc --noEmit
node scripts/check-leads.mjs
node scripts/check-car-model.mjs
~~~

## Настройки

Проект использует React, TypeScript, Vinext, Three.js и Cloudflare Workers. Для формы с фотографиями нужны D1 и Workers KV. Статический хостинг без серверных обработчиков для этой функции не подходит.

В [.env.example](.env.example) перечислены переменные окружения. Доступ к заявкам защищён паролем владельца. ADMIN_PASSWORD хранится только в секретах хостинга; настройка сервера находится в wrangler.jsonc. Уведомления в Telegram и по почте требуют подключения бота и почтового сервиса.

В репозитории находятся код и медиа сайта. Секреты, заявки клиентов, загруженные через форму фотографии, локальная база и зависимости исключены.

## Telegram

Подключение бота: https://malyarka43.danil43.workers.dev/manage/telegram. Страница доступна только владельцу. После создания бота в BotFather вставьте токен в закрытую форму и откройте выданную ссылку в Telegram Данила. Инструкция: [TELEGRAM.md](TELEGRAM.md).

- worker/ и scripts/ — сервер и сборка.
- [PROJECT.md](PROJECT.md) — состав сайта и оставшиеся настройки.
