# Разработка и публикация

## Окружение

Node.js 22.13+, npm и Git. На Windows, macOS и Linux используется переносимый профиль. Установка: npm ci. Локальные файлы окружения и служебные каталоги исключены через .gitignore.

## Локальный запуск

~~~sh
npm run dev
~~~

Сервер запускается на http://127.0.0.1:5173. База и хранилище эмулируются локально. Авторизацию владельца обеспечивает хостинг; рабочие данные доступны только после проверки email владельца.

## Сборка

~~~sh
npm run build
npm start
~~~

Сборка создаёт Worker в dist/server и клиентские ресурсы в dist/client. Команда start запускает готовую сборку локально; она не публикует сайт.

## База и фотографии

Cloudflare D1 используется через привязку DB, R2 — через BUCKET. Схема находится в db/schema.ts, миграции — в drizzle/. Миграции применяются к нужному окружению перед рабочим использованием формы. Локальная проверка API: node scripts/check-api.mjs при работающем локальном сервере.

## Переменные окружения

- OWNER_EMAIL — владелец раздела заявок.
- NOTIFICATION_EMAIL — получатель почтовых уведомлений.
- NOTIFICATION_FROM_EMAIL и RESEND_API_KEY — отправитель и ключ почтового сервиса.
- TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID — бот и получатель сообщений.

Значения задаются средствами хостинга и не хранятся в Git. После изменения переменных окружения требуется применить их к публикации и проверить доставку уведомлений.

## Проверки

~~~sh
node node_modules/typescript/bin/tsc --noEmit
node scripts/check-leads.mjs
node scripts/check-car-model.mjs
~~~

Метаданные используют текущий адрес запроса, поэтому смена домена не требует замены адреса в исходниках. Серверная защита заявок и фотографий должна сохраняться при переносе на другой хостинг. Обязательные лицензии сторонних компонентов находятся рядом с ними.
