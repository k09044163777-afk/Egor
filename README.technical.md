# Разработка и публикация

## Окружение

Node.js 22.13+, npm и Git. На Windows, macOS и Linux используется переносимый профиль. Установка: npm ci. Локальные файлы окружения и служебные каталоги исключены через .gitignore.

## Локальный запуск

~~~sh
npm run dev
~~~

Сервер запускается на http://127.0.0.1:5173. База и хранилище эмулируются локально. Раздел владельца использует HTTP Basic: имя danil и секрет ADMIN_PASSWORD длиной не менее 20 символов. Переданные посетителем заголовки идентификации удаляются сервером.

## Сборка

~~~sh
npm run build
npm start
~~~

Сборка создаёт Worker в dist/server и клиентские ресурсы в dist/client. Команда start запускает готовую сборку локально; она не публикует сайт.

## База и фотографии

Cloudflare D1 используется через привязку DB, Workers KV — через PHOTO_STORE. Схема находится в db/schema.ts, миграции — в drizzle/. KV хранит исходные фотографии с их типом содержимого; они доступны только владельцу. Миграции применяются к нужному окружению перед рабочим использованием формы.

## Переменные окружения

- ADMIN_PASSWORD — секрет доступа к заявкам. Задаётся командой wrangler secret put ADMIN_PASSWORD и не записывается в конфигурацию.
- NOTIFICATION_EMAIL — получатель почтовых уведомлений.
- NOTIFICATION_FROM_EMAIL и RESEND_API_KEY — отправитель и ключ почтового сервиса.
- TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID — бот и получатель сообщений.
- TELEGRAM_STORAGE_KEY — ключ шифрования настроек бота. При подключении через закрытую форму токен хранится в D1 зашифрованным; получатель привязывается по одноразовой ссылке. Постоянно сохраняйте этот ключ между публикациями.

Значения задаются средствами хостинга и не хранятся в Git. После изменения переменных окружения требуется применить их к публикации и проверить доставку уведомлений.

## Проверки

~~~sh
node node_modules/typescript/bin/tsc --noEmit
node scripts/check-leads.mjs
node scripts/check-car-model.mjs
~~~

Метаданные используют текущий адрес запроса, поэтому смена домена не требует замены адреса в исходниках. Серверная защита заявок и фотографий должна сохраняться при переносе на другой хостинг. Обязательные лицензии сторонних компонентов находятся рядом с ними.

## Публикация на Cloudflare

Создайте D1 и пространство KV, укажите полученные идентификаторы в wrangler.jsonc. Затем примените миграцию, соберите проект и опубликуйте Worker:

~~~sh
npm run build
npx wrangler d1 execute DB --remote --config wrangler.jsonc --file drizzle/0000_bitter_excalibur.sql
npx wrangler d1 execute DB --remote --config wrangler.jsonc --file drizzle/0001_telegram_bot.sql
npx wrangler deploy --config dist/server/wrangler.json
npx wrangler secret put ADMIN_PASSWORD --config wrangler.jsonc
~~~

Не включайте платный план для временной публикации. При достижении лимитов бесплатного тарифа отдельные запросы могут отклоняться хостингом. Собственный домен подключается позже, без изменения компонентов страницы.

Существующая база уже содержит применённые миграции. Не повторяйте создание таблиц при обычном обновлении кода. Проверка логики Telegram: node scripts/check-telegram.mjs. Настройка для владельца описана в TELEGRAM.md.
