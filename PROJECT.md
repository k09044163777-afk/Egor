# Малярка43

Сайт кузовной мастерской в Кирове. Визуальное направление: фирменная чёрно-бело-красная палитра логотипа, контрастная журнальная композиция, крупная типографика. Оригинальный логотип показан целиком на белом фоне шапки без плашки и искажения пропорций. Контент и контакты принадлежат «Малярка43». Чужие отзывы, сертификаты, статистика, тарифы и проекты не перенесены.

## Реализовано

- Адаптивная главная страница, шесть услуг с описаниями, контакты, Telegram, ВКонтакте (https://vk.com/andreevich1234), телефоны, интерактивная карта Leaflet и маршрут в 2ГИС. Точка мастерской взята из карточки 2ГИС: 58.588308, 49.584263. Карта поддерживает кнопки масштаба, колесо, перетаскивание, pinch zoom и возврат к мастерской.
- Раздел «Отзывы» после портфолио, ссылки в шапке и подвале. Данные проверены 23.11.2026 в публичной карточке [2ГИС](https://2gis.ru/kirov/firm/70000001105162492/tab/reviews): 4,9 балла, 56 оценок, 48 отзывов. Четыре выбранных коротких фрагмента с настоящими авторами, датами и оценками 5/5: Никита Черных, Дарья Подкурова, Максим Терехин, Илья Крестьянинов. Контекстные подписи отделены от цитат. Суммарно процитировано 23 слова; полные отзывы доступны по ссылкам на источник. Это датированный снимок, автоматическая синхронизация не заявлена. Данные: `app/reviews-data.ts`.
- Вращаемая 3D-модель Mercedes-Benz S65 W222 из архива владельца с выбором панелей, обоих порогов, днища, арок и полостей; всего 18 зон. HQ GLB около 3,2 МБ сохраняет все 557 659 треугольников без упрощения. Двойное разрешение, физические материалы, фактура резины, студийные отражения и мягкая тень. Свободное вращение, масштаб, семь ракурсов, клавиатура и запасной список при недоступности WebGL. Three.js и модель загружаются только при приближении к блоку; GPU не перерисовывает неподвижную сцену и сцену вне экрана.
- Подбор для всех шести услуг: полная покраска, сварка порогов и днища, комплексное восстановление после ДТП, области работ с геометрией, зоны антикора. Услуга, объём работ и участки синхронизированы с формой, проверяются сервером и сохраняются в заявке.
- Предпросмотр загружаемых фото, подсказки по съёмке повреждений, статус мастерской по московскому времени и анимации с поддержкой reduced motion. Индикатор чтения удалён по пожеланию владельца. Подпись источника карты вынесена отдельной строкой под карту, плашки Leaflet нет.
- Форма с именем, телефоном, автомобилем, услугой, желаемой датой, описанием и тремя фотографиями до 5 МБ.
- Заявки хранятся в D1, фотографии — в закрытом R2. Раздел `/manage` доступен только подтверждённому email владельца, настроенному в секретах Sites.
- Проверка согласия, российского телефона, будних и будущих дат, сигнатур файлов, ограничения частоты обращений и защита от повторной отправки одной заявки.
- Уведомления подготовлены для Resend и Telegram Bot API. Без подключения сервисов форма сообщает о сохранении заявки, не об отправке уведомлений.

## Что осталось подключить

1. Telegram: создать бота через официальный @BotFather, начать диалог с ботом, безопасно задать секреты `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в Sites. Не добавлять токен в код или Git.
2. Почта: подключить Resend с подтверждённым отправителем и задать секреты `RESEND_API_KEY`, `NOTIFICATION_FROM_EMAIL`. `NOTIFICATION_EMAIL` уже задан для указанного пользователем адреса iCloud.
3. После изменения секретов повторно развернуть сохранённую версию, затем выполнить тестовую доставку в оба канала.
4. Добавлены две реальные работы до/после: заднее крыло и покраска чёрного кузова. Между работами можно переключаться; бегунок сбрасывается в середину. Снимки сравниваются перетаскиваемым бегунком с поддержкой мыши, касания и клавиатуры, а также открываются по отдельности. Следующие работы можно добавлять по мере предоставления владельцем. Изображения на обложке и услугах пока иллюстративные; происхождение описано в ASSETS.md.
5. Текущая публикация предназначена владельцу для просмотра. Публичный доступ и собственный домен можно включить по его запросу.

## Проверка и разработка

Node.js >=22.13. `npm ci`, `npm run dev`. Миграции находятся в `drizzle/`.

Проверки: `node node_modules/typescript/bin/tsc --noEmit`, `node scripts/check-leads.mjs`, `node scripts/check-car-model.mjs`, сборка через Sites build helper. Изолированная проверка API при работающем локальном сервере: `node scripts/check-api.mjs`.

`.dev.vars` и локальная база данных не входят в исходники. Рабочая локальная проверка не отправляет уведомлений и не переносит тестовые заявки в продакшен.
